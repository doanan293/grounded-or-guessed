# Evaluation checklist for LLM-based fault localization

What we check before trusting an Acc@k number, and what each check changes when applied to every method
in this study. The table at the end is generated by `scripts/checklist.py` from `data/`; do not edit it by hand.

## The checklist

1. **Tie handling.** Report how tied scores are ranked. Stable-order ties (the earlier line wins) reward
   methods that give many lines the same score; we use the average rank of the tie group.
2. **Fixed denominator.** Divide by every program in the benchmark. A program the tool failed on is a
   miss, not a dropped row. Delta debugging reaches 38% in the released scorer only because "any hit
   counts as rank 1"; under fair scoring it ranks no line at all (0%).
3. **Execution-verified ground truth.** A line is the fault location only if a minimal one-line patch there
   makes every test pass (`flx.verify_gt`). 56 of 250 SemFault ground-truth lines are blank lines and
   65 are executed by no failing test. Report results on the original and on the repaired ground truth.
4. **Ablate every component, including undocumented ones.** SemLoc adds +1.2 to the LLM's own
   `fault_line` guess (`spectrum.apply_fault_line_prior`); the paper does not describe it. Removing it is
   the single largest change in Acc@1.
5. **Repeats and paired tests.** Run each stochastic configuration at least 3 times (one run id and one
   working directory per repeat), report mean ± sd, and test paired differences (McNemar on Acc@k
   hits, max p over repeats). Only healthy runs (`flx.run_health`) are counted.
6. **Cost.** Report LLM calls, tokens and latency per program next to accuracy (`data/llm_cost.csv`).
   A pipeline must beat a single prompt of comparable cost (here: LLM + coverage) to justify itself.

Checks 1–2 are compared on the authors' published logs (Claude Sonnet 4.6, T=0.8, all 250 programs);
checks 3–6 on our runs (Gemini 3.8 Flash, test split of 200 programs; 190 with a usable repaired
ground truth). "Before" and "after" are the two sides of each check.

## Reading the matrix

- Scoring rules move SBFL and delta debugging the most: the released scorer understates SBFL at Acc@5 and
  credits delta debugging with hits it never ranks.
- Repairing the ground truth lifts every LLM method by roughly 10–15 pp at Acc@1, and SBFL barely moves:
  the benchmark's errors penalize methods that point at the real faulty statement.
- The undocumented prior accounts for more Acc@1 than any documented component of SemLoc.
- LLM + coverage, one prompt, matches or beats the full SemLoc pipeline at about a fifth of its tokens.
