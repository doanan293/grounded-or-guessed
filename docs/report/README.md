# Báo cáo tiến độ lần 3 (25–26/11/2026)

Nhánh `bao-cao-lan-3` là bản báo cáo tiến độ lần 3, chưa đầy đủ: thêm rà soát nhãn và duyệt mù, thí nghiệm loại bỏ, các cách bổ sung, phân tích tĩnh, RQ3, đóng góp và triết lý khoa học. Mỗi lần báo cáo chỉ thêm một phần;
bản đầy đủ (bài nộp cuối) ở nhánh `main`.

| Tệp | Nội dung |
|---|---|
| `bao-cao-lan-3.pdf` | Báo cáo tiếng Việt, phiên bản `lan3` |
| `../presentation/bao-cao-lan-3.pptx` | Slide báo cáo lần 3 |
| `paper-draft.pdf` | Bản nháp bài báo tiếng Anh (phiên bản `lan3`) |

Dựng lại: `make -C docs/report vi` (mặc định `\Version` = `lan3` trên nhánh này); `make -C docs/report check`.
