# Báo cáo tiến độ lần 1 (11/11/2026)

Nhánh `bao-cao-lan-1` là bản báo cáo tiến độ lần 1, chưa đầy đủ: thông tin nhóm, phân công theo mảng việc, công cụ AI, hiện trạng sau tuần đầu; tổng quan tài liệu, câu hỏi nghiên cứu, thiết kế thực nghiệm và kết quả RQ1. Mỗi lần báo cáo chỉ thêm một phần;
bản đầy đủ (bài nộp cuối) ở nhánh `main`.

| Tệp | Nội dung |
|---|---|
| `bao-cao-lan-1.pdf` | Báo cáo tiếng Việt, phiên bản `lan1` |
| `../presentation/bao-cao-lan-1.pptx` | Slide báo cáo lần 1 |
