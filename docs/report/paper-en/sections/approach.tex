\section{Approach}
\label{sec:approach}

\subsection{Evaluation audit}
From the authors' logs we recompute every published configuration under two scorings: the \emph{authors' scoring} as
implemented in the released script (line-order tie breaking, any delta-debugging hit counted as rank one, programs that
fail to run dropped from the denominator) and our \emph{fair scoring} (average-rank ties, fixed denominator). We then
remove the undocumented guess bonus, check whether the counterfactual step changes any ranking, and re-execute SemLoc
with the paper's own model (Claude Sonnet~4.6) on the dev split.

\subsection{Three label sets}

\textbf{Repaired (tests decide).}
\GtBlankN{} of the 250 ground-truth lines are blank and \GtNotExecutedN{} programs have no failing test reaching the
fault line. We re-derive fault locations with a \emph{minimal-fix oracle}: a line is a fault location if replacing it (or
filling a blank line, for omissions) with a small edit makes every test pass. An edit is small if its token-level edit
distance to the original line (tokens are identifiers, numbers and single punctuation characters) is at most two or at
most a third of the line's tokens. For each program: (1) for each ground-truth line, an LLM proposes candidate edits
(GPT-6 luna, two attempts at $T=\ConstTemperature$, then up to four; a second pass with Claude Sonnet~5.5 for lines still
unverified) and the tests decide; (2) a ground-truth line that admits a passing small edit is \emph{confirmed};
(3) only if no failing test reaches the original line, lines within four of it are searched and the closest line with
the smallest passing edit replaces it (\emph{corrected}); (4) otherwise the line stays \emph{unverified}. The oracle
confirms \GtConfirmedN{} locations and corrects \GtCorrectedN; \GtUnverifiedN{} reachable lines keep their original labels
(no proposed edit passed), and \GtUnverifiableN{} programs cannot be verified and are dropped. Fixes written onto blank
lines name no rankable statement and are also dropped, leaving \GtRepairedN{} programs. Because executed labels are never
searched for alternatives, the oracle cannot detect two equivalent fix locations.

\textbf{Reviewed (LLM pre-review, team review).} To check \emph{every} label, an LLM (Claude Fable 5.1, high reasoning)
read each program, its tests and its label, and judged the label right, wrong (proposing a line) or one of two lines of
a two-line fault; it ran the tests on its own fixes for many cases. Then \ReviewReviewersN{} team members reviewed
\ReviewHumanN{} labels---the \GtCorrectedN{} the oracle had moved and every label the LLM judged wrong---with links to the
code and tests, the candidate lines and the LLM's verdict as a suggestion; they agreed with the suggestion in
\ReviewAgreeN{} of \ReviewHumanN{} cases. The first author overrode \ReviewOverrideN{} cases on test evidence (two-line
faults that one-line fixes cannot repair, omission faults placed on the \texttt{return} statement as in sibling programs,
and one mis-numbered LLM citation). The result covers all \LabaudAllN{} programs, none on a blank line, with
\LabaudAllTwoLine{} two-line labels.

The \LabaudAllExtended{} two-line extensions and the labels the LLM judged right rest on the LLM pre-review alone; no human
reviewed them.

\textbf{Use.} The repaired labels involve no LLM judgment of location (an LLM proposes edits, the tests decide) and carry
the main results; the reviewed labels are complete but
LLM-suggested, which may favor LLM-based methods, so we use them as a sensitivity check. Every main result is also given on
the original labels.

\subsection{Grounded-vs-guessed decomposition}
SemLoc's line score is the spectrum score plus a bonus of \ConstPriorWeight{} on the LLM's guessed line. We define a
two-player game \{guess, spectrum\}: $v(S)$ is Acc@$k$ when lines are ranked by the signals in $S$ only ($v(\emptyset)=0$;
``guess only'' ranks the guessed line alone; ``spectrum only'' ranks by spectrum score with average-rank ties); with both,
the scores equal SemLoc as released. We report the marginal values $v(\{\text{guess}\})$, $v(\{\text{spectrum}\})$ and
$v(\{\text{guess},\text{spectrum}\})$ together with the Shapley split. Because Acc@$k$ is a mean of per-program hits, the
aggregate Shapley value is the mean of per-program values, which lets us bootstrap confidence intervals by program and by
template cluster. An extended game adds raw Ochiai (added with weight one) and counterfactual re-ranking as two more
players; its grand coalition is a different system from SemLoc.

\subsection{Methods compared}
\textbf{LLM + failing tests (ours).} One call at $T=\ConstTemperature$ whose prompt gives the line-numbered program, the
numbers of failing and passing tests, the statement that the program has exactly one faulty line, and each failing
test's name with its first error line; the model returns its five most suspicious lines as JSON. This is the developers'
practice made reproducible. The prompt was fixed before looking at test results.

\textbf{Coverage ablation.} \emph{LLM + failing tests + coverage} is the same prompt with every line annotated
\texttt{[f=$e_f$/p=$e_p$]} (and one sentence explaining the annotation). Against \emph{LLM direct}---SemLoc's own
direct-prediction mode, which sees the program only---the two paired contrasts separate the effect of the failing tests
from that of coverage.

\textbf{CovGate} post-processes SemLoc's line scores with coverage. Writing $\sigma(s)$ for the spectrum score, $g$ for
the guessed line and $F$ for the lines executed by some failing test,
\begin{equation}
c(s) = \mathbb{1}[s\in F]^{\gamma}\,\bigl(\sigma(s) + \beta\,\mathbb{1}[s=g] + \lambda\,\mathrm{Ochiai}(s)\bigr),
\label{eq:covgate}
\end{equation}
where $\gamma\in\{0, 1\}$ switches a coverage gate, $\lambda\in\{\ConstLambdaGrid\}$ weights Ochiai, and the bonus $\beta$
is either always \ConstPriorWeight{} or kept only when execution supports $g$; a fourth switch promotes lines confirmed by
the counterfactual patches. Selected on the dev split, CovGate has no gate and the original bonus, with $\lambda$ =
\ConstLambdaOriginal{} (original) or \ConstLambdaRepaired{} (repaired labels): an Ochiai tie-breaker.

\textbf{Propose-and-verify} uses the tests as arbiter: LLM + failing tests proposes lines; for the first $k$, the LLM
writes a small fix at that line (the oracle's proposer and size criterion), the patched program runs against the tests,
and lines with a passing fix move to the front. A \PavGridSize-point grid ($k$, attempts per line, order among verified
lines, maximum fix size) is evaluated offline from one widest run on the dev split, three repeats; the selection rule
(mean dev Acc@1 over the original and reviewed labels; the repaired labels are excluded because they were built by the
same fix-and-test mechanism) was fixed in code before running.

\textbf{Voting} merges three answers of LLM + failing tests by summed reciprocal rank (dev split).

\textbf{Static analysis.} Pinned versions of ruff (default and all rules) and pyrefly (type checking) run on all 250
programs; a program counts as hit when a diagnostic sits on a labeled line, compared with the hits expected if the
flagged lines were spread at random over the program's code lines.
