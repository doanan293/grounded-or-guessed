# Reproducing every table and figure

Four levels, from cheapest to most expensive. Levels 0–2 need no LLM and no network at run time.

| Level | What it reproduces | Needs | Command |
|---|---|---|---|
| 0 | LaTeX tables, figure and number macros from the committed CSVs | this repository | `python scripts/make_tables.py && python scripts/make_numbers.py` |
| 1 | every CSV in `data/` from the archived run outputs | + the run archive (`grounded-or-guessed-runs-<date>.tar.gz`) | `tar xzf grounded-or-guessed-runs-*.tar.gz && scripts/regenerate_all.sh` |
| 2 | the SemLoc / baseline runs themselves, replaying every LLM answer from the cache | + the run archive | `FLX_LLM_OFFLINE=1 scripts/run_semloc.sh <new empty workdir> gemini-3.8-flash-high 0.8 semloc_test_gemini_r1` (workdir from `flx.workdir.make_workdir`) |
| 3 | fresh runs | an OpenAI-compatible LLM endpoint (`.env.example`, `infra/proxy/`) | same as level 2 without `FLX_LLM_OFFLINE`, with **new run ids** |

Level 1 is checked end to end in Docker (the regenerated `data/` and `docs/report/generated/` are byte-identical to the committed ones):

```bash
docker build -t grounded-or-guessed .
docker run --rm grounded-or-guessed                       # unit tests (offline)
docker run --rm -v $PWD/dist:/dist grounded-or-guessed bash -c \
  "tar xzf /dist/grounded-or-guessed-runs-*.tar.gz && scripts/regenerate_all.sh"
```

Level 2 works from any directory: prompts carry no absolute paths, and the cache key is
sha256(model, system, user, temperature, run id). Use the original run id (e.g. `semloc_test_gemini_r1`) to replay
that repeat; a cache miss in offline mode stops with `offline cache miss` instead of calling the network.

## Building the archive

`python scripts/export_artifact.py` writes `dist/grounded-or-guessed-runs-<date>.tar.gz`: outputs of every finished,
healthy run in `data/runs.csv`, the LLM call log filtered to those runs, the cached responses of their successful
calls, and a sha256 manifest. It refuses to write the archive if any file matches a credential or e-mail pattern
(`flx.secrets_scan`).
